# Smart Hydration Base

An IoT-based Smart Hydration Base developed using Wokwi, MQTT, Python, and Unity.

## Project Modules

### Electronics
- ESP32 firmware
- Sensor integration
- Wokwi circuit diagram

### Integration
- MQTT communication bridge
- TCP communication with Unity
- Hydration sensor data processing
- Unity dashboard
- 3D water-level visualization

## Technologies Used
- C++
- C#
- Python
- MQTT
- TCP
- JSON
- Unity
- Wokwi
